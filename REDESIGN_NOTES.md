# Code Craft - public site redesign

## v2 Rebrand (Direction A)
- **Identity:** Cobalt on cool white. Calm, credible, conversion-focused.
- **Palette:** Light background (#EEF0F4), white surfaces (#FFFFFF), cobalt primary (#2B45FF).
- **Typography:** Archivo (400, 500, 800) for everything. Mono is system ui-monospace.
- **Logo:** Wordmark "codecraft." (Archivo 800, tight tracking, cobalt period). Small icon is a `</>` bracket.
- **Live URL:** https://codecraftdigitalstudio.vercel.app

### What changed
- Replaced the dark charcoal/chartreuse theme with the new light tokens.
- Updated Hero, Navbar, Footer, and Admin panels to use the new tokens.
- Added `EditDemo` and `NeedsPicker` interactive components.
- Updated OG image and favicon.

### What could not be verified
- Visuals and admin flows (no dev server run).
- Lighthouse scores (table predates this rebrand).

## Previous Identity (v1, retired)
Dark charcoal ground (`#0B0F14`), chartreuse accent (`#A3E635`), Outfit/Geist fonts.
